# Movie Watchlist API 🍿

A modern, fast REST API built with .NET 8 Minimal APIs. This project allows users to track movies they want to watch, leave star ratings, write reviews, and calculate watchlist statistics.

Features Built

.NET 8 Minimal APIs: All routing and logic contained in a clean, unified structure.

String Searching: Filter your watchlist by searching for partial movie titles.

Math Operations (LINQ): Automatically calculates the average rating of all watched movies.

Data Validation: Ensures star ratings are restricted to a 1-5 scale.

How to Run Locally

Ensure you have the .NET 8 SDK installed.

Create a folder named MovieWatchlistApi and place the project files inside.

Open a terminal in that folder and run dotnet run.

Navigate to http://localhost:<port>/swagger in your browser to test the endpoints!
